# About this repository

A public snapshot of Faculty, a single-instructor teaching web app, published for review as a portfolio piece. It was made
from a private repository by an export script: history is not included, identifying hosts, addresses, account identifiers
and every real person's name were replaced with placeholders, and third-party tool settings were left out. Every name,
number and address in the tests and documents is invented; the export checked the copy against the real roster.

Two commercial fonts (Berkeley Mono and Suisse Int'l) are licensed to the original deployment and are not included; their
faces load only from a copy installed on the viewer's computer (`static/fonts/README.md`).

Paths such as `/mnt/nvme/Teaching` are the original deployment's. Nothing here reaches a real school, mail or grading
service; the checks run against fakes (`manage_checks.py`, `CHECKS.md`).
